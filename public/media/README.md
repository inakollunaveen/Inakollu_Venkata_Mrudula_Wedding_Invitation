# Media Directory

Place your wedding media files here:
- `music.mp3` — Background wedding nadaswaram / opening song ("కళ్యాణం కమనీయం...")
- `invitation.mp4` — Wedding video invitation 1 (సాంప్రదాయ కళ్యాణ వైభోగం - Royal Red theme)
- `invitation2.mp4` — Wedding video invitation 2 (దివ్య మంగళ పెండ్లిపిలుపు - Divine Floral theme)
- `groom.jpg` — Groom photo (left)
- `couple.jpg` — Bride & groom photo (middle)
- `bride.jpg` — Bride photo (right)

The application automatically checks for these files and plays them smoothly.
